# Charles Sales

Desenvolvedor Full Stack Júnior em Salvador, BA, cursando Análise e Desenvolvimento de Sistemas na UCSAL.

## Sobre mim

Trabalho com desenvolvimento web ponta a ponta, do banco de dados à interface. No back-end, uso Node.js, Express e TypeScript para construir APIs REST e implementar regras de negócio. No front-end, desenvolvo interfaces com Vue.js. Também modelo e mantenho bancos de dados relacionais (PostgreSQL e MySQL) e NoSQL, escrevendo consultas SQL avançadas com CTEs, agregações JSON e stored procedures.

Na parte de infraestrutura, trabalho com Docker e faço deploy em nuvem com Google Cloud Platform e Terraform. No dia a dia, uso Git e GitHub com Git Flow, participo de revisões de código e atuo em times ágeis.
